## Description
BudgetApp is an enterprise-inspired personal finance application that combines secure authentication, AI-assisted transaction categorization, and advanced financial analytics. Built using ASP.NET Core, React, TypeScript, PostgreSQL, CQRS architecture, and JWT/MFA authentication, the platform allows users to upload and analyze financial statements, manage budgets, track savings goals, monitor investments, and visualize spending patterns through D3.js dashboards. Intelligent recommendations, automated reporting, budget alerts, and historical trend analysis help users make data-driven financial decisions while maintaining privacy through statement sanitization and secure data handling.
